# 小兒復健初診

兒童復健門診初診輔助工具：左側點選或輸入，右側即時生成英文病歷，可一鍵複製。

- 里程碑檢核，估算各領域 DA / DQ（門診初估，不取代標準化工具）
- 依填寫內容建議 ICD-10 診斷與常見處置
- 評量換算：DQ、SD／百分位／標準分數／T 分數互換，以及 CDIIT、Bayley / WPPSI-IV、PDMS-2、Movement ABC、學前兒童語言障礙評量表、CLST 判讀

## 使用

單一檔案 `index.html`，沒有後端、不需安裝。直接用瀏覽器開啟，或用 GitHub Pages 發布：
Settings → Pages → Source 選 `main` 分支、`/ (root)`。

## 資料與隱私

輸入內容只存在瀏覽器分頁的 sessionStorage，關閉分頁即清除，不會傳到任何伺服器。
請勿輸入姓名、病歷號等可識別個人的資料。

## 聲明

僅供臨床人員個人輔助使用，DA、DQ 與建議診斷需由醫師確認，不構成診斷依據。
ICD-10 代碼中標示「補充」者請對照所屬機構使用的版本。
